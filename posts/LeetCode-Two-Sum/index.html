LeetCode #1 - Two Sum

Created2026-03-21|Updated2026-03-21|LeetCode
|Post Views:

Problem

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

Difficulty: Easy
Link: https://leetcode.com/problems/two-sum/

Constraints:

  • Only one valid answer exists
  • You may not use the same element twice

My First Thought (Brute Force)

Loop through every pair and check if they sum to target.

// O(n²) - too slow
for (int i = 0; i < nums.length; i++) {
    for (int j = i + 1; j < nums.length; j++) {
        if (nums[i] + nums[j] == target) return new int[]{i, j};
    }
}

Problem: O(n²) time — too slow for large inputs.

Optimised Solution (HashMap)

Use a HashMap to store each number and its index as we scan.
For each number, check if target - num already exists in the map.

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                return new int[]{map.get(complement), i};
            }
            map.put(nums[i], i);
        }
        return new int[]{};
    }
}

Time: O(n) | Space: O(n)

Why This Works

Step Example: nums=[2,7,11,15], target=9
i=0, num=2 complement=7, map empty → put {2:0}
i=1, num=7 complement=2, map has 2 → return [0, 1] ✅

Key Takeaway

When you need to check “does X exist in what I’ve seen before?”, think HashMap.
Trade space O(n) for time O(n).

Pattern: Hash Map lookup
